تغییرات این نسخه (مینی‌اپ)
- مسیر فایل‌ها absolute شد؛ /admin-panel/ دیگر فایل JS را 404 نمی‌گیرد.
- برای همه مسیرها index.html فیزیکی + 404.html ساخته می‌شود (Render فایل _redirects را اجرا نمی‌کند).
- آدرس API را در public/config.js (API_BASE_URL) بدون build دوباره تنظیم کنید؛ یا VITE_API_BASE_URL موقع build.
- اگر API اشتباه باشد (پاسخ HTML)، پیام خطای روشن با دکمه «تلاش دوباره» نشان داده می‌شود.
- اگر چک عضویت بیش از ۳.۵ ثانیه طول بکشد، صفحه پشت اسکلت نمی‌ماند.

نسخه ۲ (علت اصلی صفحه‌ی خالی/اسکلت)
- tsconfig.json هشت پکیج را به نسخه‌های ساده در src/shims نگاشت می‌کرد و esbuild همان‌ها را در بیلد می‌گذاشت (zustand ساختگی selector را نادیده می‌گرفت → fetchUser is not a function). نگاشت‌ها و پوشه‌ی shims حذف شد و پکیج‌های واقعی استفاده می‌شوند.
- RoleGate در صفحه ادمین به‌خاطر loading=true اولیه هرگز درخواست نمی‌فرستاد؛ اصلاح شد.
